## Honest limits

- The suite measures the verifier set against a small, hand-written adversary. A different adversary can find different escapes.
- Resistance is not a proof. It is a floor that grows as cases are added; a new attack should become a new fixture, not a new argument.
- A control case only catches over-blocking. It does not tell you whether the contract is useful on real work.
