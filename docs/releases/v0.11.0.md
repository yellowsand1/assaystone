# v0.11.0 — The gate reaches the agent, and the operator gets a card

Released 2026-11-25.

0.10.0 made decisions signed and criteria owned. 0.11.0 puts the gate where the
agent stops, and turns the scattered evidence into one operator view.

## Highlights

- **The Stop hook runs the capability gate.** `hook install claude-code
  --manifest .assaystone/capability.json --stage shadow` writes
  `.assaystone/hook.json`; at Stop the hook evaluates the manifest on the working
  tree. A failure or escalation prints the oracle table and, in `block` mode,
  refuses the stop. The hook never loads the owner or receipt keys and never
  signs: CI remains the authoritative record. Hook errors fail open.
- **`capability status`.** One read-only card per capability: criteria coverage,
  the current stage's critical gap, stage requirements/approvals/rollback/chain,
  owner approval validity, trail chain and last outcome per stage, receipt
  verification, and a residual-risk list. `--json` returns the same structure.
- **The self-gate prints its card.** The CI job that gates this repository now
  writes the status card into the job summary, next to the trail and receipt
  artifacts.
- **Assaystone's own `.assaystone/hook.json`** points at its self-capability.

## Evidence

- 455 tests, lint clean, CI on Python 3.10–3.13.
- The self-gate runs on every push and PR, uploads `assaystone-self-gate`, and
  prints the card.
- The two real-agent runs and the lifecycle trial remain the behavioral evidence.

## Known limits

- A Stop hook is a local setting; an agent that can edit the settings can disable
  it. CI with a receipt is the enforcement that survives. Branch protection must
  make the gate required; the repository does not claim that is configured.
- A full test suite at every Stop is slow. Use a fast hook capability and keep
  the full suite in CI.
- The hook is Claude Code only; other agents need their own exit integration.
- The card is per capability; there is no cross-capability portfolio view yet.
- The HMAC trust model, approvals without expiry, the conflict-without-waiver
  gap, and the semantic gap remain as stated in 0.10.0.
