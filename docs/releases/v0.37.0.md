# v0.37.0 — Say what you saw

Released 2026-11-27.

A verifier judges what it can see. When an execution is compacted, delegated, or
imported through a tracing vendor, the verifier sees a summary, and a judgment
about a summary is not a judgment about the execution. This release makes the
view part of the decision.

## Highlights

- **`Trace.view`.** Every trace records `native`, `restored`, `imported`,
  `compacted`, `delegated`, or unknown. Git episodes and runtime guards are
  native; a Claude Code transcript with a compaction marker is compacted;
  LangSmith / Langfuse / OpenTelemetry imports are imported.
- **The certificate says which view it judged.** `subject.view` carries the raw
  metadata; `assurance.transport` carries view, adapter, truncated, risk, and a
  reason. `certificate show` prints one line:
  `transport compacted (risk high), adapter claude-code`.
- **`require_native_view`.** A contract can require that a pass rest on a native
  or restored view. A pass built on a summary escalates with
  `transport required: verifier saw a compacted view`. This is the same shape as
  `require_measured`: a property the decision must have, not a footnote.

## Evidence

- 761 tests, 5 skipped; ruff clean; CI on Python 3.10–3.13.
- The audit demo reports `transport native (risk low), adapter claude-code`.
- A synthetic compacted trace reports high risk and escalates under
  `require_native_view`; a native trace passes.
- The repository's own production gate passes before publishing.

## Known limits

- Detection is shallow: it sees explicit compaction markers and the adapter's
  own provenance. It cannot prove that an imported transcript is complete.
- `restored` is a declaration by the adapter; it is only as good as the
  provenance restored.
- The gate is opt-in. Start with the report, turn the gate on where it matters.
- This does not recover lost evidence. It tells you the evidence is thin.
- No external user yet. P1 remains three external repositories, one published
  defect the tests missed, and one external contract.
