# v0.9.0 — Close the loop with the agent

Released 2026-11-25.

0.8.0 put the gate in CI. 0.9.0 puts the acceptance criteria in the agent's
input, and records what that changes.

## Highlights

- **`capability brief`.** Render a manifest as a task brief: the typed criteria,
  the oracle bindings, the stage requirements, the exact gate command, and three
  rules — do not edit tests/CI/the manifest to pass, stop and explain a conflict
  with a criterion, and a pass is evidence rather than a claim.
- **`transcript` oracle `ignore`.** Paths or globs excluded from the session
  artifacts. The gate's own `.assaystone/` tooling is not a change under review.
- **The agent experiment.** The same task was run twice on a real Maven module:

  | | without the brief | with the brief |
  |---|---|---|
  | source change | rename applied | one edit, then reverted |
  | build | pass | pass |
  | gate | **fail** (public API) | **pass** (tree restored) |
  | agent ran the gate | 0 times | 3 times |
  | final report | "done, build verified" | "conflict; stopped" |

  The case study, including what the run does not prove, is
  [docs/case-study-lifecycle.md](../case-study-lifecycle.md).
- **`examples/capability/java_api_diff.py`.** A `javap -public` baseline
  comparison as a command payload. It is an example connector, not a primitive.
- **A 30-minute design-partner lifecycle script** in
  [docs/adoption.md](../adoption.md).

## Evidence

- 428 tests, lint clean, CI on Python 3.10–3.13.
- The lifecycle trial, the SQL/shadow domain, and the real-agent runs are
  documented with their limits: the defect was scoped, no human approved
  anything, and the SQL domain is a fixture.

## Known limits

- A conflict between a task and a criterion currently ends in a stop. There is
  no approved-exception mechanism; that is the next gap a real deployment will
  expose.
- The brief tells the agent to run the gate; the experiment does not show that
  agents infer unstated criteria.
- Semantic correctness still routes to a human; the Goodhart semantic family
  remains 0% resistance.
- The trail proves integrity, not authenticity; unsigned approvals are files.
