# v0.24.0 — The session and the decision point at each other

Released 2026-11-25.

Session evidence and gate decisions were two files that never referenced each
other. A receipt could not name the session it came from; a session could claim a
passing gate that was never recorded. They are now one chain.

```text
session record ──entry_hash──▶ trail entry ──head──▶ receipt ──facts──▶ session, record digest
```

## Highlights

- **Oracles publish facts.** `runtime` publishes `session`, `record` (the file
  digest), `entry`, `record_commit`; `drill` publishes its action, compensation,
  outcome, and commit. Facts reach the trail entry and the signed receipt.
- **`runtime` verifies the decision it cites.** With `"trail"` in the payload,
  the oracle checks the entry hash exists on that trail and that both agree about
  the commit.
- **`receipt verify --runtime-record FILE`** compares a receipt with the session
  file it cites. An edited record fails with *the runtime record does not match
  the one the receipt cites*.
- **The supervisor does not cite itself.** The hook's gate skips `runtime` and
  `drill` and reports them as *not evaluated here*. Without this the hook
  deadlocked: requiring a session record at the stage the hook evaluates made
  every record say `escalate`.
- **The hook writes the record before any early return** and ignores
  `.assaystone/` when hashing the work, because the evidence directory is not the
  work and changes as the record is written.

## Evidence

- 602 tests, lint clean, CI on Python 3.10–3.13, seven required checks.
- Ran end to end: the hook recorded session `sess-43` with an entry hash, the CI
  gate passed, the receipt carried the facts, verification against the record
  passed, and one appended byte broke it.

## Known limits

- Facts are recorded, not signed separately: the receipt signs them as part of
  its body, and the record itself remains unsigned.
- A session record is written by a local hook; an agent that can edit the hook
  configuration can stop producing them. CI with a receipt is the enforcement
  that lasts.
- The semantic gap, canary traffic control, and the sandbox are unchanged.
