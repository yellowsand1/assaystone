# v0.21.0 — Prove the compensation works

Released 2026-11-25.

Reversibility had one mechanism: a check that the release commit reverse-applies.
That is a claim about a patch. This release adds the stronger statement — take
the state, do the irreversible thing, undo it, and require the state to be
identical again — and makes the release of this repository use it.

## Highlights

- **`capability drill`.** A manifest declares, per irreversible action, its
  compensation and the state paths to compare:

  ```json
  "reversibility": [
    {"id": "build-dist", "action": "build_pkg", "compensation": "clean_dist",
     "state": ["dist"]}
  ]
  ```

  The drill hashes the state, runs the action, hashes again, runs the
  compensation, and takes a third hash. The action must pass **and change
  something**; otherwise the drill proves nothing and fails. The final hash must
  equal the first.

- **The `drill` oracle.** A stage can require the record. A failed drill is
  `fail`; a missing record, one recorded under different rules, for another
  commit, or too old is `escalate`.

- **Directories are hashed by content.** Hashing `dist/` as a file returned
  `absent`, which would have made the check vacuous.

- **This repository drills its own release.** The release workflow runs the
  drill before the production gate and uploads
  `.assaystone/drills/build-dist.json` with the trail and receipt.

## Evidence

- 573 tests, lint clean, CI on Python 3.10–3.13, seven required checks.
- Ran locally: drill pass (`absent → dir-sha256 → absent`), production gate pass
  with the drill criterion, owner approval re-signed after reviewing the change
  with `capability diff` — which classified it as tightening, not weakening.
- This release is the first one whose production gate requires a drill.

## Known limits

- The drill compares content hashes. It does not know whether a remote system was
  compensated; a database migration needs a state path that reflects it (a dump,
  a checksum file) or a command that asserts it.
- Drill records are machine-local and unsigned: evidence that a supervisor ran
  the drill, not a signed decision.
- Still no canary traffic control and no sandbox. Compensation is closed; the
  rest of reversibility is not.
