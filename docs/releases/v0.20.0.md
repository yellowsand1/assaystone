# v0.20.0 — The evidence now knows which code it is about

Released 2026-11-25.

Going back through the original nine deployment gaps turned up a bypass, not a
missing feature: the stage chain compared the capability and the manifest digest
but not the commit. This release closes that, adds the two gaps that were still
empty — reversibility and cost — and puts the supervisor on the evidence side.

## Highlights

- **The stage chain binds the commit.** `production` with `"after": "canary"`
  now refuses a canary pass recorded for other code:

  ```text
  the canary pass was recorded for commit abc123..., not def456...
  ; re-run canary on this code
  ```

  Every trail entry records `HEAD`; the status card marks an older decision
  `[stale commit]`; `capability list --strict` treats a stale decision for the
  current lifecycle as critical.

- **`gate --dry-run`** executes only oracles that do not declare
  `"mutates": true`. It never returns `pass`, reports a read-only failure as
  `escalate`, and refuses `--receipt`, so it cannot impersonate a decision.

- **A verification budget.** `cost_usd` per oracle, `budget_usd` per stage. The
  gate keeps the declared order, stops before an oracle it cannot afford, and
  escalates. Cost reaches the result, the trail, and the receipt.

- **The supervisor writes evidence (`runtime` oracle).** The Stop hook records
  the commit, session, per-file hashes, gate outcome, and audit count. The oracle
  fails a session that ended in a failing gate and escalates a record that no
  longer describes the code. The transcript oracle stays testimony.

- **The manifest digest is stable across upgrades.** Adding `budget_usd` changed
  every digest and invalidated an owner's approval — the self-gate refused on CI
  and exposed it. The serialised shape is frozen, and a pinned-digest test guards
  it, because changing it invalidates every approval in the world.

## Evidence

- 560 tests, lint clean, CI on Python 3.10–3.13, seven required checks.
- The self-gate refused this release's own branch until the digest bug was fixed.
- The runtime record was exercised end to end: pass immediately, escalate after
  an edit, escalate after a new commit.

## Known limits

- Reversibility is still partial: dry-run and a rollback check, no canary traffic
  control, no compensation transaction, no sandbox.
- The runtime record is unsigned and machine-local; signed decisions remain
  receipts. It is written by the Stop hook, so an agent that can edit the hook
  configuration can disable it — CI with a receipt is the enforcement that lasts.
- The semantic gap is unchanged: behavioural change with no oracle escalates.
- The digest shape is now frozen. A future field must appear only when set, or it
  invalidates every approval.

## Upgrade

```bash
pip install --upgrade assaystone==0.20.0
pip install "assaystone[crypto]==0.20.0"   # optional Ed25519
```

If your manifest declared `manifest_approval`, upgrade and re-check: this release
keeps existing approvals valid, but verify with `capability status`.

For the GitHub Action, pin `yellowsand1/assaystone@v0.20.0`.
